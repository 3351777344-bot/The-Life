# The Life

An interactive life-path exploration prototype built with Vue 3, Vite, Three.js, and a small Node.js backend.

## Setup

```bash
npm install
```

Copy `.env.example` to `.env`, then fill in the API credentials required by your model provider.

## Development

Start the backend API:

```bash
npm run backend:dev
```

Start the frontend:

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project Layout

- `backend/` - Node.js API server and AI provider integration.
- `src/` - Vue frontend views, components, and services.
- `docs/` - Current project notes and integration documentation.
- `docs/archive/` - Historical handoff and acceptance materials.
- `docs/source-materials/` - Original product documents and extracted source material.
- `scripts/legacy/` - Early one-off scripts kept for reference.
