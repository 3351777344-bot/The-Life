# 答辩展示讲稿

更新时间：2026-05-18
适用分支：`Tilams`

## 1. 30 秒开场版

“我们做的是一个基于 AIGC 的人生规划与决策辅助互动产品。它不是简单给用户一个答案，而是把同一个人面对不同人生选择时的不同路径，用可视化、可对比、可复盘的方式展开。用户先输入真实背景和偏好，系统生成多条路线，再通过对比、属性变化、AI 顾问和终局报告，让用户更直观地理解不同选择的代价和收益。”

## 2. 3 分钟标准讲法

### 第一部分：产品定位

“我们注意到，很多人在专业选择、职业转向、城市发展和长期规划上，真正缺的不是信息本身，而是一个能把这些信息和个人情况结合起来的工具。所以我们把产品定位成一个‘人生分叉路模拟与决策辅助系统’。”

### 第二部分：核心流程

“用户进入系统后，第一步是基础建模，也就是输入年龄、职业、城市、收入、技能和风险偏好等真实条件。这样后面的路线不是抽象推演，而是尽量结合用户现实约束。”

“第二步是命轨视图。这里我们把人生关键选择做成一棵可展开的图谱，用户能看到不同节点之间的关系，而不是只停留在线性问答。”

“第三步是衍化。系统会基于用户状态生成多条路线，比如更激进的成长路线和更稳健的平衡路线。每条路线都有可行性、难度和预期收益。”

“第四步是对比。这里是产品很关键的价值点，因为同一个人，在不同选择下，职业、财务、关系、健康这些维度会形成不同走势。我们希望用户看到的不是一个结论，而是差异本身。”

“第五步是观心。这里会把路线选择带来的属性变化、趋势和影响来源进一步可视化，帮助用户理解路径背后的结构变化。”

“第六步是论道。用户可以和 AI 顾问继续讨论，例如这一条路线最大的现实风险是什么，未来一年最应该补什么能力。”

“最后一步是归途，也就是终局报告。系统会生成后悔指数、人生建议和整段旅程统计，让整个推演过程有一个可复盘的收口。”

### 第三部分：产品价值总结

“所以我们的产品不是替用户做决定，而是降低用户理解复杂选择差异的门槛。我们希望把人生选择这件事，从模糊焦虑，转成可视化比较和更有依据的讨论。”

## 3. 5 分钟详细讲法

### 3.1 为什么做这个产品

“传统的人生建议工具经常存在两个问题。第一，建议太泛，不结合用户真实背景。第二，结果太线性，用户看不到不同路径之间的差别。我们做这套产品，就是想把‘个人现实条件 + AIGC 推演 + 可视化比较’结合起来。”

### 3.2 产品最有特色的三点

1. “不是静态问卷，而是动态路径推演。”
2. “不是只给单一路线，而是强调不同路线间的结构性差异。”
3. “不是只给结论，而是把过程也做成可复盘、可讨论的内容。”

### 3.3 展示时重点强调的功能

1. 基础建模：强调现实约束条件输入。
2. 命轨图谱：强调树状可视化与节点扩展。
3. 路线对比：强调这是产品价值展示的核心。
4. AI 顾问：强调上下文相关建议，而不是泛化聊天。
5. 终局报告：强调复盘和收口。

### 3.4 如果老师问“和普通聊天机器人有什么区别”

推荐回答：

“区别在于我们不是只做聊天，而是把用户信息、路径结构、属性变化和终局报告都组织起来。聊天只是其中一个环节，它服务于整条人生分叉路的体验。”

### 3.5 如果老师问“为什么要做对比页”

推荐回答：

“因为很多真实人生决策最重要的不是‘有没有一个正确答案’，而是理解不同选择之间的权衡。对比页就是把这种权衡显性化。”

## 4. 每一步一句话提示

1. 入局：`先建模，再推演。`
2. 命轨：`把抽象人生选择变成可展开图谱。`
3. 衍化：`给出多条路线，而不是单一答案。`
4. 对比：`把差异展示出来，是本产品的核心。`
5. 观心：`路线影响不是一句话，而是多维变化。`
6. 论道：`AI 顾问用于延伸讨论，而不是代替决策。`
7. 归途：`最终价值在于可复盘，而不只是可生成。`

## 5. 结束收口

推荐结束语：

“我们希望这套产品能让用户在面对复杂人生选择时，不只是更快下结论，而是更清楚地看到不同路径背后的代价、机会和长期影响。”
