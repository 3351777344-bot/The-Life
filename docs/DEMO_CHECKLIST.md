# 演示检查清单

更新时间：2026-05-18
适用分支：`Tilams`

## 演示前

1. 确认当前分支为 `Tilams`
2. 确认项目可正常启动或构建
3. 确认默认用户信息未被异常改动
4. 确认默认路线能够正常生成
5. 确认至少两条路线可加入对比
6. 确认顾问页可正常输入问题
7. 确认终局页可以正常打开

## 演示中

1. 不要频繁修改大量基础信息
2. 优先选择“平衡型”场景选项
3. 优先展示“快速成长路线”和“平衡发展路线”
4. 不要在未选路线前过早跳到终局页
5. 如果某一步失败，优先使用页面已有兜底提示继续讲

## 演示后

1. 如果需要 повтор演示，使用“重新开始”
2. 确认本地状态没有残留异常
3. 如有临场发现问题，补充到新的 `change-log` 或阶段总结中
