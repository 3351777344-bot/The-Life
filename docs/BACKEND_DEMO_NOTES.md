# 后端演示说明

更新时间：2026-05-19

## 这次后端做了什么

1. 后端提供 `/api/scenario`、`/api/routes`、`/api/advisor/reply`、`/api/regret-report`、`/api/planning-file/extract`。
2. 优先调用本地 Ollama，失败时自动回退到稳定兜底结果。
3. 每次请求都会打印请求 ID 和耗时，方便现场排查。

## 比赛现场怎么讲

1. 先说这是一个“人生分叉路推演”项目，不是纯聊天机器人。
2. 再说前端负责展示，后端负责生成场景、路线、顾问建议和终局报告。
3. 文件上传这块说明：文本文件可接入，Word 文档目前保留兜底摘要。
4. 重点强调：主流程稳定、可演示、可复盘。

## 推荐启动方式

```bash
npm run backend:dev
npm run dev
```

## 一句话收尾

“这个版本的重点不是做成完整商业系统，而是把人生分叉选择做成可视化、可对比、可讲清楚的比赛演示。”
